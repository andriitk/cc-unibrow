FAQ

Questions, answered.

Is my code sent anywhere?

No. Unibrow has no network code, no analytics and no account. Hook data goes over a private local socket to the app on the same Mac and stays in memory.

Does it need special permissions?

No. It never reads your project files, so macOS never asks about Documents or Desktop. Accessibility is only for the optional Exact Window Focus, which raises the exact window of a session.

Does it slow Claude Code down?

No. Hooks that only report events run in the background and finish in milliseconds.

Where does it work?

Wherever Claude Code runs on your Mac. Not in cloud sessions or over SSH, where Claude Code runs on another machine.

Can I use it only in some projects?

Yes. Install the plugin per project with claude plugin install cc-unibrow@cc-unibrow --scope project.

How much does it cost?

Nothing. Unibrow is free and open source under the MIT license.
